# 前端「去 AI 化」优化改动说明

> 适用对象：`frontend/desktop/`（医学问询智能体桌面端）
> 改动性质：**纯视觉与文案层重构，零功能改动**。所有 DOM 结构、类名、交互逻辑、接口调用均保持不变；仅 `style.css` 整体重写、`index.html` 与 `app.js` 中的文案/图标字符串调整。
> 查看方式：浏览器 **硬刷新**（Windows `Ctrl+F5` / Mac `Cmd+Shift+R`），因静态资源已加版本号 `?v=20260903a` 强制刷新缓存。

---

## 一、设计目标与总方向

现状问题：原界面是典型「AI 产品模板」——钉钉蓝主色、登录页 `135deg` 蓝色渐变、全站统一 8px 圆角、纯无衬线字体、机械感文案（"知识库驱动 · 防幻觉 · 数据加密隔离"）、对称居中的卡片布局。这些都指向"这是又一个聊天机器人"的冷感印象。

优化方向：**温润诊所（Warm Clinic）** 风格——用低饱和松绿 + 暖陶土点缀 + 纸感米白，取代冷蓝；用衬线标题制造编辑感与人味；用不对称圆角、有机光斑、呼吸式微交互打破模板感；文案从"功能说明书"转为"会说话的伙伴"。

| 维度 | 优化前（AI 模板感） | 优化后（人性化） |
|---|---|---|
| 配色 | 钉钉蓝 + 蓝色渐变 | 松绿 + 陶土 + 暖纸白，暖调阴影 |
| 布局 | 居中对称、统一圆角 | 不对称圆角、有机光晕、左侧活跃指示 |
| 字体 | 全站无衬线 | 正文无衬线 + 标题衬线（人文对比） |
| 文案 | 功能参数式 | 自然、有温度、像真人对话 |
| 交互 | 静态、无反馈 | 入场动画、悬停抬起、按下回弹、打字呼吸 |

---

## 二、布局（Layout）

**1. 打破对称与千篇一律的圆角**
- 头像、品牌徽标、消息气泡均采用**不对称圆角**（如 `26px 26px 26px 8px`、`18px 18px 18px 4px` 收一角），模拟手绘方块的随性，去除"精确但冰冷"的工业感。
- 消息气泡：助手气泡左收尖、用户气泡右收尖，形成类似微信/iMessage 的真人对话轮廓，而非两端齐平的方盒。

**2. 登录页：暖纸底 + 有机光斑**
- 移除蓝色渐变背景，改为暖米白底 + 右上角松绿光晕、左下角陶土光晕两大不规则圆形光斑（`radial-gradient` + `border-radius:50%`），营造柔和、非对称的呼吸空间。

**3. 导航与面板的有机指示**
- 一级导航活跃项增加**左侧小竖条指示器**（替代整块高亮填充），克制且有方向感。
- 会话列表活跃项用**左侧细竖条 + 浅描边卡片**取代整块蓝色填充，降低视觉噪音。
- 聊天区右上角加一抹**松绿光晕**，打破纯白模板感。

**4. 节奏感**
- 卡片、面板、输入区采用 `12 / 16 / 22px` 三档圆角梯度，配合 `8–22px` 不等内边距，形成有机而非等距的机械节奏。

## 三、配色（Color）

| 变量 | 旧值 | 新值 | 作用 |
|---|---|---|---|
| 主背景 | `#ffffff` | `--paper #f6f3ee` | 暖纸白，不刺眼 |
| 主色 | `#0089ff` 钉钉蓝 | `--brand #3c8c7d` 低饱和松绿 | 沉静、可信、去科技蓝 |
| 点缀色 | 无 | `--clay #c47a4e` 陶土橙 | 用于「开个新话题」等关键动作，制造品牌个性 |
| 文字 | `#171a1f` | `--ink #2c2823` 暖近黑 | 更柔和 |
| 边框 | `#e5e7eb` 冷灰 | `--line #e7ded1` 暖灰描边 | 一体化暖调 |
| 阴影 | 冷黑半透明 | 暖棕半透明 `rgba(60,45,30,…)` | 阴影也"变暖" |
| 成功/危险 | 纯色 | `--ok #2f8f6b` / `--danger #bd4a32`（带柔底） | 更耐看 |

- 导航栏由深蓝改为**深松炭 `#28332f`**，与松绿主色同源，整体更协调。
- 「开个新话题」按钮用陶土色，让页面有一个温暖的视觉锚点，避免全站一个蓝。

**预期效果**：第一眼从"又一个蓝色 AI 工具"变成"一个安静、可信的健康伙伴"，降低用户的防备感与模板疲劳。

---

## 四、字体（Typography）

- **正文**：保留 `PingFang SC / 微软雅黑` 等无衬线栈，保证中文可读性与系统兼容（不依赖外网字体）。
- **标题 / 品牌字**：新增衬线栈 `"Noto Serif SC","Songti SC",serif`，应用于登录标题、各视图 `panel-title`、聊天标题、弹窗标题。
- 区块标题前加一道**松绿→陶土的渐变竖条**（`::before`），作为品牌签名细节。
- 行高由 `1.75` 提升至 `1.85`、字间距略放宽，增加留白与呼吸感。

**预期效果**：衬线标题带来"编辑部 / 诊所手册"的人文气质，与纯无衬线的"SaaS 后台"形成区隔，强化品牌记忆点。

## 五、文案（Copy）

原则：把"功能参数"翻译成"人话"，保留必要信息但去掉机器腔。关键改动：

| 位置 | 旧文案 | 新文案 |
|---|---|---|
| 登录副标题 | 知识库驱动 · 防幻觉 · 数据加密隔离 | 你的健康小笔记，安静地陪你理清身体的信号 |
| 登录提示 | 每位用户拥有独立加密数据空间…… | 每次对话都只属于你一个人，资料加密存放，不和任何人混在一起 |
| 空状态（问诊） | 你好，我是你的问诊助手。请描述你最近的身体不适…… | 你好，我是你的健康小助手。哪里不太舒服，慢慢跟我说说？ |
| 输入框占位 | 描述症状，如：最近三天咳嗽、喉咙痛…（Enter 发送…） | 说说哪里不舒服？比如：这两天有点咳嗽、嗓子疼……（回车发送…） |
| 知识库侧栏提示 | 切换到「分块分析…」可查看知识库质量与病情关联 | 想看看知识库"脑子里"记了什么？试试「分块分析 / 检索验证 / 知识图谱」 |
| 检索验证标题 | 检索验证（已入库内容是否可被检索到） | 检索验证（看看存进去的内容，能不能被找出来） |
| 图谱空状态 | 点击节点查看病情关联与「可能引发的其他关联病情」 | 点一下某个病情节点，看看它和哪些情况相关、又可能引发什么。 |
| 报告库提示 | 报告在问诊中生成时自动入库，按系统分类归档 | 问诊时生成的报告会自己归好类存进来。 |
| 识药说明 | 上传药物照片……智能识别……避免误用 | 拍张药盒、说明书……我来认一认……并提醒你哪些药不能一起吃、有哪些潜在风险。 |
| 按钮 | 登录 / 生成检查报告 / 开启新话题 | 登录 / 整理一份检查报告 / 开个新话题 |
| 助手头像 | 🤖 机器人 | 🌿 叶子（去机器人符号，去 AI 脸谱化） |
| 新话题提示 | 已开启新话题，请描述本次问诊的不适症状 | 新话题已经开好啦，说说这次哪里不舒服吧～ |

**预期效果**：用户从"在被系统审问"转为"在和一个懂行的朋友聊天"，信任与倾诉意愿提升；🤖 → 🌿 直接消解"机器人"标签。

## 六、交互（Micro-interactions）

全部为纯 CSS 动画，不新增任何 JS 逻辑：

1. **消息入场**：`.msg` 加载时 `msgIn` 淡入 + 上移 10px，模拟消息"落定"的节奏，而非瞬间出现。
2. **打字指示**：把生硬的块光标 `▍` 换成 `···` 呼吸式三点（`typingPulse` 透明度循环），更柔和。
3. **按钮反馈**：主按钮/幽灵按钮悬停**轻微抬起 + 暖色阴影**，按下 `scale(.98)` 回弹，有"可按"的实体感。
4. **卡片悬停**：文档、报告、提醒、记录、分块等卡片悬停**上移 2–3px + 阴影加深**，建立层次。
5. **导航与列表**：图标悬停上浮、活跃态左侧小竖条；会话项活跃态改为描边卡片而非蓝底。
6. **输入框聚焦**：暖绿聚焦光环（`box-shadow` 3px 品牌色），替代生硬蓝边。
7. **弹窗 / Toast**：弹窗 `pop` 缩放入场，Toast 从上方 `toastIn` 弹入。
8. **图谱关联项**：悬停 `translateX(2px)` 微位移，提示"可点击"。
9. **细滚动条**：暖灰圆角滚动条，取代系统冷灰默认条。

**预期效果**：界面"活"了起来——每一次点击、悬停、收到消息都有克制的反馈，像被认真对待，而非面对一块静态面板。

## 七、明确未改动项（功能保全）

- 所有视图、面板、导航结构、信息架构**原样保留**。
- 所有 `id` / `class` / 事件绑定 / 接口调用**未改动**，`app.js` 仅替换了字符串常量（文案与一处 emoji）。
- 登录/注册、会话、知识库上传与检索验证、图谱、报告库、识药（图片/视频）、档案、提醒等**全部功能不变**。
- 仅新增 CSS 自定义属性与 `@keyframes`，不引入任何新依赖。
